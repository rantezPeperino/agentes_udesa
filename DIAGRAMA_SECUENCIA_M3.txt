================================================================================
                    DIAGRAMA DE SECUENCIA - PIPELINE M3
================================================================================

El proyecto M3 es un sistema de evaluación de agentes. El flujo completo es:

┌─────────┐
│ Usuario │
└────┬────┘
     │ python eval/run.py
     │
     ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                          FASE 1: EVALUACIÓN (run.py)                        │
│                                                                               │
│  Para cada escenario en scenarios/:                                          │
│                                                                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ ESCENARIO 1: study-with-key (easy)                                 │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │                                                                      │   │
│  │  1. Cargar escenario JSON                                           │   │
│  │     ├─ user_message: "Abre la puerta principal"                     │   │
│  │     ├─ goal: {type: "item_open", target: "puerta_principal"}       │   │
│  │     └─ initial_world: {rooms, inventory, locked_items}             │   │
│  │                                                                      │   │
│  │  2. Crear agente                                                    │   │
│  │     └─ agent = build_agent()                                        │   │
│  │                                                                      │   │
│  │  3. Registrar herramientas del mundo                                │   │
│  │     ├─ look() → "Ves: llave bajo alfombra, puerta cerrada"         │   │
│  │     ├─ examine("llave") → "Llave de hierro"                        │   │
│  │     ├─ take("llave") → "✓ Tomaste la llave"                        │   │
│  │     └─ use("llave", "cerradura") → "✓ Puerta abierta"              │   │
│  │                                                                      │   │
│  │  4. Ejecutar agente                                                 │   │
│  │     ╔════════════════════════════════════════════════════════════╗ │   │
│  │     ║  BUCLE AGENTE (max_iterations=20)                         ║ │   │
│  │     ╠════════════════════════════════════════════════════════════╣ │   │
│  │     ║  ITERACIÓN 1                                              ║ │   │
│  │     ║  ───────────                                              ║ │   │
│  │     ║  INPUT:                                                   ║ │   │
│  │     ║    User: "Abre la puerta principal"                       ║ │   │
│  │     ║    Herramientas disponibles: [look, examine, take, use]   ║ │   │
│  │     ║                                                            ║ │   │
│  │     ║  LLM CALL:                                                ║ │   │
│  │     ║    agent._llm.chat(                                       ║ │   │
│  │     ║      messages=[{"role": "user", "content": "..."}],       ║ │   │
│  │     ║      tools=[ToolSchema(look), ...],                       ║ │   │
│  │     ║      system="Eres un asistente útil"                      ║ │   │
│  │     ║    )                                                       ║ │   │
│  │     ║                                                            ║ │   │
│  │     ║  RESPONSE:                                                ║ │   │
│  │     ║    tool_calls: [                                          ║ │   │
│  │     ║      {name: "look", arguments: "{}", id: "tool_0"}        ║ │   │
│  │     ║    ]                                                       ║ │   │
│  │     ║    content: "Voy a explorar la habitación primero"         ║ │   │
│  │     ║                                                            ║ │   │
│  │     ║  EJECUCIÓN DE HERRAMIENTA:                                ║ │   │
│  │     ║    tool_func = agent._tools["look"]                       ║ │   │
│  │     ║    tool_output = tool_func()                              ║ │   │
│  │     ║      → "Ves: llave bajo alfombra, puerta cerrada"         ║ │   │
│  │     ║                                                            ║ │   │
│  │     ║  ACUMULAR EN HISTORIAL:                                   ║ │   │
│  │     ║    history.append({                                       ║ │   │
│  │     ║      "role": "user",                                      ║ │   │
│  │     ║      "content": "Abre la puerta principal"                ║ │   │
│  │     ║    })                                                      ║ │   │
│  │     ║    history.append({                                       ║ │   │
│  │     ║      "role": "assistant",                                 ║ │   │
│  │     ║      "content": "Voy a explorar..."                       ║ │   │
│  │     ║    })                                                      ║ │   │
│  │     ║    history.append({                                       ║ │   │
│  │     ║      "role": "tool",                                      ║ │   │
│  │     ║      "content": "Ves: llave bajo alfombra..."             ║ │   │
│  │     ║      "tool_use_id": "tool_0"                              ║ │   │
│  │     ║    })                                                      ║ │   │
│  │     ║                                                            ║ │   │
│  │     ║  GUARDAR PASO:                                            ║ │   │
│  │     ║    steps.append(AgentStep(                                ║ │   │
│  │     ║      tool_name="look",                                    ║ │   │
│  │     ║      tool_input="{}",                                     ║ │   │
│  │     ║      tool_output="Ves: llave bajo alfombra...",           ║ │   │
│  │     ║      error=None                                           ║ │   │
│  │     ║    ))                                                      ║ │   │
│  │     ║                                                            ║ │   │
│  │     ║  ¿HAY MÁS tool_calls?                                     ║ │   │
│  │     ║    → SÍ, continuar bucle                                  ║ │   │
│  │     ╚════════════════════════════════════════════════════════════╝ │   │
│  │                                                                      │   │
│  │     ┌─────────────────────────────────────────────────────────────┐ │   │
│  │     │  ITERACIÓN 2                                                │ │   │
│  │     │  ───────────                                                │ │   │
│  │     │  LLM ve historial completo:                                 │ │   │
│  │     │    [{"role": "user", "content": "Abre la puerta..."},       │ │   │
│  │     │     {"role": "assistant", "content": "Voy a explorar..."},  │ │   │
│  │     │     {"role": "tool", "content": "Ves: llave..."}]           │ │   │
│  │     │                                                              │ │   │
│  │     │  LLM RESPONSE (2da llamada):                                │ │   │
│  │     │    tool_calls: [{name: "take", arguments: "{item: ...}"}]   │ │   │
│  │     │    content: "Voy a tomar la llave"                          │ │   │
│  │     │                                                              │ │   │
│  │     │  EJECUCIÓN:                                                 │ │   │
│  │     │    take("llave") → "✓ Tomaste la llave"                     │ │   │
│  │     │                                                              │ │   │
│  │     │  HISTORIAL CRECE:                                           │ │   │
│  │     │    ... + [assistant, tool de iteración 2]                   │ │   │
│  │     └─────────────────────────────────────────────────────────────┘ │   │
│  │                                                                      │   │
│  │     ┌─────────────────────────────────────────────────────────────┐ │   │
│  │     │  ITERACIÓN 3                                                │ │   │
│  │     │  ───────────                                                │ │   │
│  │     │  SIMILAR AL ANTERIOR: use("llave", "cerradura")             │ │   │
│  │     │  → "✓ Puerta abierta"                                       │ │   │
│  │     └─────────────────────────────────────────────────────────────┘ │   │
│  │                                                                      │   │
│  │     ┌─────────────────────────────────────────────────────────────┐ │   │
│  │     │  ITERACIÓN 4                                                │ │   │
│  │     │  ───────────                                                │ │   │
│  │     │  LLM RESPONSE: SIN tool_calls                               │ │   │
│  │     │    content: "La puerta está abierta. Tarea completada."      │ │   │
│  │     │                                                              │ │   │
│  │     │  ¿HAY tool_calls?                                           │ │   │
│  │     │    → NO → BUCLE TERMINA                                     │ │   │
│  │     │                                                              │ │   │
│  │     │  RETORNA:                                                   │ │   │
│  │     │    AgentResult(                                             │ │   │
│  │     │      answer="La puerta está abierta...",                    │ │   │
│  │     │      steps=[                                                │ │   │
│  │     │        AgentStep(tool_name="look", ...),                    │ │   │
│  │     │        AgentStep(tool_name="take", ...),                    │ │   │
│  │     │        AgentStep(tool_name="use", ...)                      │ │   │
│  │     │      ],                                                     │ │   │
│  │     │      input_tokens=150,                                      │ │   │
│  │     │      output_tokens=80                                       │ │   │
│  │     │    )                                                        │ │   │
│  │     └─────────────────────────────────────────────────────────────┘ │   │
│  │                                                                      │   │
│  │  5. Verificar goal                                                  │   │
│  │     check_goal(world, goal)                                         │   │
│  │     └─ puerta_principal.open_state == "open" → TRUE ✅              │   │
│  │                                                                      │   │
│  │  6. RESULTADO PARA ESTE ESCENARIO:                                  │   │
│  │     {                                                               │   │
│  │       "scenario_id": "study-with-key",                              │   │
│  │       "difficulty": "easy",                                         │   │
│  │       "passed": true,                                               │   │
│  │       "steps": 3,                                                   │   │
│  │       "input_tokens": 150,                                          │   │
│  │       "output_tokens": 80,                                          │   │
│  │       "total_tokens": 230,                                          │   │
│  │       "latency_seconds": 2.3,                                       │   │
│  │       "error_type": null,                                           │   │
│  │       "optimal_steps": 3                                            │   │
│  │     }                                                               │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                               │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ ESCENARIO 2: color-locks (medium)                                  │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │ SIMILAR AL ANTERIOR PERO:                                           │   │
│  │ - Más iteraciones (cadena de cofres)                                │   │
│  │ - Más tokens consumidos                                             │   │
│  │ - Posible fallo si el agente se pierde                              │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                               │
│  ... (8 escenarios totales) ...                                             │
│                                                                               │
│  7. GUARDAR TODOS LOS RESULTADOS                                            │
│     ┌─ eval/results/baseline.json                                           │
│     │  [                                                                    │
│     │    {"scenario_id": "study-with-key", "passed": true, ...},            │
│     │    {"scenario_id": "color-locks", "passed": true, ...},               │
│     │    {"scenario_id": "library-search", "passed": false, ...},           │
│     │    ...                                                                │
│     │  ]                                                                    │
│     └─ 8 objetos JSON (un por escenario)                                    │
│                                                                               │
└─────────────────────────────────────────────────────────────────────────────┘
